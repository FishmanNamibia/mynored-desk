# NSA Dashboard Images

This directory contains images used in the NSA dashboard, particularly for the Welcome to NSA slider widget.

## Directory Structure

### `/nsa/`
Images for NSA Vision, Mission, and Core Values slides:
- `vision.jpg` - Image representing NSA's vision
- `mission.jpg` - Image representing NSA's mission  
- `values.jpg` - Image representing NSA's core values

### `/board/`
Images for Board Members:
- `member1.jpg` - Board Chairperson
- `member2.jpg` - Board Vice Chairperson
- `member3.jpg` - Board Member
- `member4.jpg` - Board Member

### `/exco/`
Images for Executive Committee Members:
- `member1.jpg` - Statistician General
- `member2.jpg` - Deputy Statistician General
- `member3.jpg` - Director: Economic Statistics
- `member4.jpg` - Director: Social Statistics

## Image Requirements

- **Format**: JPG, PNG, or WebP
- **Recommended Size**: 800x600px minimum
- **Aspect Ratio**: 4:3 or 16:9 for best display
- **File Size**: Keep under 500KB for optimal performance

## Fallback Behavior

If images are not found, the slider will display:
- For Vision/Mission/Values: The slide will show without the image
- For Board/EXCO members: Initials will be displayed in a colored circle

## Updating Images

1. Add your images to the appropriate directory
2. Name them according to the structure above
3. The dashboard will automatically load them
4. No code changes required!
